## 核心特色
1. **大螢幕翻頁時鐘（預設首頁）**：巨型時間數字翻牌，開場與中場休息大螢幕常駐。
2. **計時器（獨立頁面）**：支援快捷 1/3/5/10/15 分與「分:秒自訂」，倒數結束前急促提示音與時間到警報。
3. **排行榜（個人榜 ╳ 分組榜連動）**：
   - 分組加扣分時，自動同步計入全組成員個人積分。
   - 每滿 5 分可啟動隨機抽獎一次（內建 10 個免花費驚喜獎項，支援老師自由自訂獎品池）。
4. **單一焦點公佈欄（支援大螢幕 QR Code）**：
   - 一次展示一則超大字公告，排版舒適易讀。
   - 支援鍵盤左右箭頭或簡報筆快速翻頁。
   - 智慧附帶大螢幕 QR Code（一鍵帶入報到網址，點擊可放大讓後排掃描，即時連動報到人數）。
   - 內建「例行 / 歷史公告庫」，隨選隨投放到大螢幕、重複使用與修改。
5. **課堂音效引擎**：Web Audio API 原生合成（抽籤、加分、扣分、中獎、時間到警報）。
6. **隨機點名抽籤**：單人/雙人/四人代表，具備防重複中獎機制。
7. **分組與計分**：預設純序號（第 1 組、第 2 組...），點擊可原地自訂組名。
8. **QR Code 報到與名冊同步**：支援現場手機掃描填寫學校、姓名、年資與痛點，支援 GAS 前後端雲端同步。

### 方式 B：串接真實 Google Apps Script 與 Google 試算表（完整前後端）
1. 前往 [Google 雲端硬碟](https://drive.google.com) 新增一個 Google 試算表（例如命名為：`1017花蓮研習簽到表`）。
2. 在試算表上方選單點選 **「擴充功能」 ➔ 「Apps Script」**。
3. 在編輯器中建立兩個檔案：
   - 程式碼檔案 `Code.gs`：複製本專案 [`Code.js`](file:///c:/antigravity/講師/花蓮國語文輔導團/課堂儀表板/Code.js) 的完整內容貼入。
   - HTML 檔案 `checkin_mobile.html`：複製本專案 [`checkin_mobile.html`](file:///c:/antigravity/講師/花蓮國語文輔導團/課堂儀表板/checkin_mobile.html) 的內容貼入。
4. 點選右上角 **「部署」 ➔ 「新增部署作業」**：
   - 種類選擇 **「網頁應用程式」** (Web App)。
   - 說明填寫：`v1.0`。
   - 執行身分選擇：**「我」**。
   - 誰可以存取：**「任何人」** (Anyone)。
5. 複製生成的 **網頁應用程式網址**（格式如 `https://script.google.com/macros/s/.../exec`）。
6. 開啟大螢幕儀表板 [`index.html`](file:///c:/antigravity/講師/花蓮國語文輔導團/課堂儀表板/index.html)，點擊右上角 **⚙️（設定）**，貼上該網址：
   - 大螢幕上的 QR Code 會自動變成該連結！
   - 現場老師掃碼即可填寫，點選「雲端同步」即可一鍵抓回全部真實老師名冊！
